nanolize 分层版本：v0 → v1 → v2 → v3

新版本做成 host agent → controller → author / test designer / verifier 三层，一版一版把流程交给 controller。这页只放核心设计：流程图、每一步谁来定、分层。

v0

controller 排 author。封存之后首版怎么写由它定，parallel 开或关、两个作业都是。parallel 关着时所有会话一个接一个。

v1

封存之后每一步都先问 controller；封存之前，设计 leaf 测试怎么排由它定。保存、第一次全量对比先问它；parallel 开着时导入等不等由它定。

v2

封存之前要不要再补一次设计，由 controller 定。baseline 的抓取和封存本身仍由 mainline 执行。

v3

一个 controller 按关系表调度整个作业。不再分 main job 和 draft job；程序只管一张关系表，写明工具之间的依赖和互斥。

工作包、验证、风险、待定事项等实施细节，都在 实施方案（markdown） 里。
