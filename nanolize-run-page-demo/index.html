nanolize run 页面与 trace 页面 demo

前两个页面是 run 页面本身，上面带一个播放条，可以逐帧看一次运行；第三个是 trace（trajectory）页面，可以把一次运行按时间回放，并看任意时刻的功能图。右上角可切换中英文。

pair / parallel 开和关的四种组合 四条手写的时间线（项目 confkit 是虚构的），页面上画出来的内容由 run 页面自己的模型代码生成。
