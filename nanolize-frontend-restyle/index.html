前端风格更新：前后对比

nanolize 的四个页面（run 页面、选择页、报告页、轨迹页）换成了同一套主题：设计页的三款字体、J-2 标志、和主页设计 7 一致的深色风格，背景是调暗了的星空。改动在分支 frontend-restyle 上，还没有推送。

三项要求分别怎么做的

对应你提的三条。

01

字体和标志

  • 标题和大数字用 Source Serif 4，正文和界面用 DM Sans，标签、读数、编号和时间用 Geist Mono；字号按设计页的九级（11–24px）。
  • 三款字体以数据形式放在样式表里，页面仍然不从外部加载任何东西；中文用读者的系统字体。字体的许可文本随包一起分发。
  • J-2 标志在每个页面的左上角。run 页面的浏览器标签图标也换成它，右下角带一个表示运行状态的色点。
02

风格和星空背景

  • 配色是设计页的深色色板：平时只有灰和绿；蓝、黄、红只表示状态（运行中或选中、部分或警告、失败）。
  • 背景取自主页的星空：保留三种星色和少量带光晕的亮星，去掉连线、动画和绿色，星星更少、更暗、不动，只从卡片之间和页边露出来。
  • 按钮、状态标签、分段开关改成设计 7 的圆角胶囊；页面里只有“提交”这一类主要动作是实心白色按钮。
03

页面设计

  • 四个页面原来各有一套颜色（run 页面浅色、选择页紫色、轨迹页深浅两套），现在共用一份主题，样式表里不再直接写颜色值。
  • 层级靠细线和明暗区分，去掉了粗的彩色边框和阴影；选择页节点以外的文字，最小字号从 8px 提到 11px。
  • run 页面上表示进度的东西（阶段、里程碑、步骤）都按状态上色：完成绿、进行中蓝、等你处理或有缺口黄、失败红、还没到灰；阶段归谁用小图标表示。

需要你知道的取舍

这几处是我自己定的，不合适可以改。

只做了深色一套
run 页面和轨迹页原来会跟随系统在浅色和深色之间切换；现在四个页面都是深色，和主页一致。要保留浅色模式需要另做一套色值。
每个独立页面多约 0.3 MB
字体放进了页面本身（选择页、报告页、轨迹页、演示页都是单个文件）。run 页面由本机服务提供，字体只加载一次。
时间线的阶段色没有换
那六种颜色是为了区分类别选的，不属于状态色。已在新的底色上重新验过色盲可辨性和对比度，全部通过。
单文件页面没有标签图标
仓库里有测试规定这些页面不能带任何链接标签，所以只有 run 页面换了图标；标志本身四个页面都有。
页面内容和交互没有动
除了页头，没有改文字、布局结构和脚本逻辑；改的是样式表、三个页面模板的页头，以及几处提供页面的代码。
